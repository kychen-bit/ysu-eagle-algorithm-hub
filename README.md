# 燕鹰算法知识库

燕山大学 RoboMaster 燕鹰战队算法组维护的公开算法资料聚合与技术博客。

## 本地开发

```bash
npm install
npm run docs:dev
```

生产构建：

```bash
npm run docs:build
```

## 投稿

知识文档、博客与资源索引均使用 Markdown 编写。提交前请阅读 [CONTRIBUTING.md](./CONTRIBUTING.md) 和站内投稿指南。
