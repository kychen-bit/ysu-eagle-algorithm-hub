# RoboMaster 算法开源项目

## 官方与通用工具

- [RoboMaster GitHub](https://github.com/RoboMaster)：官方 SDK、裁判系统和相关资料。
- [OpenCV](https://github.com/opencv/opencv)：计算机视觉基础库。
- [ROS 2](https://docs.ros.org/)：机器人软件通信与工具生态。

## 选择项目时看什么

不要只看 Star 数量。优先检查许可证、维护时间、硬件条件、构建说明、数据与模型是否公开，以及代码是否能在当前平台复现。
