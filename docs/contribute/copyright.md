# 转载与版权说明

本站是公开资料聚合与技术博客，不会把其他作者的文章包装为燕鹰原创。

## 转载文章必须包含

- 原作者或来源项目。
- 可访问的原始链接。
- 原许可证（能够确认时）。
- 本站做过的格式、结构或内容调整说明。

## 原创、转载与整理

- `original`：由燕鹰成员原创并授权本站发布。
- `repost`：保留原文主体，仅做站点适配。
- `curated`：汇总多个来源或经过明显重写，仍逐项标注参考资料。
