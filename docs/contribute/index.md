# 参与共建

你不需要会前端开发。会写 Markdown、能说明来源并完成基本自检，就可以投稿。

## 投稿流程

1. 在 GitHub 打开目标目录，选择新建或编辑文件。
2. 使用知识文档或博客模板填写 Frontmatter。
3. 转载内容填写原作者、原始链接、来源项目和许可证。
4. 提交到新分支并创建 Pull Request。
5. 根据审核意见修改，合并后网站自动发布。

## 适合投稿的内容

- 环境配置和故障排查记录。
- 算法原理、实验和失败样例。
- 项目部署、调参和交接说明。
- 比赛或训练复盘中可公开的技术部分。
- 值得长期保存的外部资料整理。
