# 关于燕鹰算法知识库

燕鹰算法知识库由燕山大学 RoboMaster 燕鹰战队算法组维护，面向新人、在役队员、历届成员及其他 RoboMaster 学习者公开。

网站的目标不是展示“我们知道多少”，而是让一个具体问题更容易被找到、复现和继续改进。

## 公开边界

本站不保存账号、密钥、内网地址、未公开比赛参数和对局策略。公开内容不代表燕山大学官方立场。
