# 公开项目手册模板

## 项目解决什么问题

用一段话说明输入、核心处理和输出，避免只写项目代号。

## 支持环境

列出操作系统、硬件、编译器和关键依赖版本。

## 获取与构建

提供从干净环境开始的完整命令，并说明成功构建的标志。

## 配置

说明每个公开参数的含义、单位、默认值和影响范围。

## 运行与验证

给出启动命令、正常日志、输入输出和最小验证步骤。

## 标定与调试

描述前置条件、操作顺序、结果文件和失败现象。

## 常见问题

按“现象 → 检查 → 原因 → 处理 → 验证”书写。

## 维护信息

记录维护者、更新时间、相关文档和公开仓库地址。
