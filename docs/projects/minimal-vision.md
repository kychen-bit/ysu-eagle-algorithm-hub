# 最小视觉项目

## 目标

读取视频或相机图像，完成颜色空间转换、阈值分割、轮廓筛选和结果可视化，同时记录帧率与关键中间量。

## 推荐结构

```text
minimal-vision/
├── CMakeLists.txt
├── README.md
├── config/
├── include/
├── src/
├── tests/
└── assets/
```

## 验收

1. 能在干净构建目录完成编译。
2. 输入源和阈值通过配置文件设置。
3. 输出包含原图、二值图、候选轮廓和处理耗时。
4. 输入结束、图像为空或配置错误时给出可理解的错误信息。
5. README 说明环境、构建、运行和预期结果。

完成后进入[装甲板识别阶段](/learning-path/stage-3)。
