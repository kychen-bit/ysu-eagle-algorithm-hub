# 算法组学习路线

这不是“建议阅读列表”，而是一条可执行的训练顺序。每一阶段都说明目标、必读材料、实践任务和完成标准。遇到陌生概念时先完成当前阶段，不要同时铺开所有方向。

| 阶段 | 主题 | 最终产出 |
| --- | --- | --- |
| [0](/learning-path/stage-0) | 准备与环境 | 可复现的 Linux 开发环境 |
| [1](/learning-path/stage-1) | Linux、Git 与 C++ | 能参与一个规范仓库的协作 |
| [2](/learning-path/stage-2) | OpenCV 与相机 | 读取相机并稳定处理图像 |
| [3](/learning-path/stage-3) | 装甲板识别 | 输出可靠的目标角点与类别 |
| [4](/learning-path/stage-4) | PnP 与坐标系 | 从像素位置得到空间位姿 |
| [5](/learning-path/stage-5) | 预测与通信 | 形成识别—解算—控制闭环 |
| [6](/learning-path/stage-6) | 部署与维护 | 在车载设备复现并排查系统 |

::: tip 使用方式
每个阶段先完成“必读”，再做实践任务。能够复述概念不算完成，产生可运行程序、日志或复盘记录才算完成。
:::

## 学习原则

1. 先复现，再优化；先形成闭环，再讨论局部极限。
2. 记录设备、系统、依赖和参数版本，避免“只在我的电脑上能跑”。
3. 任何连续两小时没有进展的问题，都应整理最小复现后向组内提问。
4. 重要结论提交到知识库，不把技术积累留在聊天记录里。
