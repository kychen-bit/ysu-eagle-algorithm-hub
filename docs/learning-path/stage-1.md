# 阶段 1：Linux、Git 与 C++

## 目标

能阅读和修改基础 C++ 项目，使用 Git 分支、提交和 Pull Request 与其他人协作。

## 必读

- [Git 基础](/knowledge/imported/qd/Introduction_to_Linux/Git)
- [C++ 与构建系统](/knowledge/cpp-build)
- [C++11 语法](/knowledge/imported/qd/Technical_Basics_and_Development_Techniques/C++11_grammar)
- [CMake 入门](/knowledge/imported/qd/Project_Tutorial/cmake)

## 实践任务

创建一个 CMake 管理的命令行项目：读取一组二维点，计算中心与包围盒，编写至少两个独立源文件，并通过分支和 Pull Request 合并。

## 完成标准

项目能在干净目录中通过 `cmake` 和构建命令编译；提交历史清楚；README 能指导另一名队员复现。
